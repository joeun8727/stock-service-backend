# 08 — 법적 / 컴플라이언스 (필수 준수)

> ⚠️ 이 규칙은 **모든 API 응답과 데이터 저장에 강제 적용**됩니다.

## 1. 면책 문구 (모든 응답 필수)

모든 API 응답의 `disclaimer` 필드에 면책 문구 포함:

```
"본 정보는 투자 추천이나 자문이 아니며, 정보 제공만을 목적으로 합니다.
투자 결정과 그 책임은 전적으로 이용자 본인에게 있습니다."
```

- `ApiResponse<T>`에 `disclaimer` 필드를 두고 항상 채움.
- 누락된 응답이 없도록 공통 응답 래퍼/인터셉터에서 보장.

## 2. 뉴스 원문 재배포 금지

- **저장 가능**: 헤드라인, 출처명, 원문 링크(URL), 발행일, **자체 생성 LLM 요약**, 메타데이터.
- **저장/제공 금지**: 뉴스 원문 본문(full text).
- 뉴스 응답에는 항상 출처 링크를 포함하고, 사용자가 원문은 출처에서 보도록 유도.
- DB `NewsArticle`에 `content`/원문 본문 컬럼을 두지 않음 (`data-model.md`).

## 3. 유사투자자문업 회피 표현 가이드 (한국 자본시장법)

특정 종목에 대한 **매수/매도/보유 권유로 해석될 표현 금지.**

| 금지 표현 | 대체 표현 |
|----------|----------|
| "매수 추천", "지금 사세요" | "시가총액 상위 종목입니다" |
| "유망주", "강력 추천" | "성장 지표가 높은 종목" |
| "목표가 ○○원" | (제공하지 않음) |
| "오를 것입니다" | "최근 매출성장률은 ○○%입니다" |

- LLM 요약 생성 프롬프트에도 **"투자 권유 표현 금지, 사실 기반 요약만"** 명시.
- "랭킹/스크리닝"은 **객관적 지표 기반 정렬**임을 명확히 (추천이 아님).

## 4. API 키 / 보안

- 모든 외부 API 키는 환경변수로만 주입. 코드/로그/응답에 절대 노출 금지.
- `.env`, 키 포함 파일은 `.gitignore`.
